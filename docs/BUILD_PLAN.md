# Signal Build Plan

## Phase 1 — Foundation
- Repository and development conventions
- Next.js application shell
- Supabase/PostgreSQL schema
- Authentication/workspaces
- Environment/secrets management
- Automated tests and CI

## Phase 2 — Intelligence core
- Provider abstraction
- Research orchestration
- Evidence normalisation
- Evidence fusion
- Contradiction detection
- Unified decision engine
- Explainable scoring

## Phase 3 — Product workflows
- Company intelligence
- Opportunity feed
- Recommended actions
- Outreach drafts
- Outcome recording
- Research Lab

## Phase 4 — Data integrations
- Customer import
- CRM connection framework
- CRM sync and deduplication
- Background monitoring

## Phase 5 — Live research
- Provider adapters
- 100-company real-world cohort
- Cost and latency measurement
- SME coverage testing
- Human precision review

## Phase 6 — Commercial production
- Subscription tiers
- Usage controls
- Billing
- Security hardening
- Observability
- GDPR/privacy controls
- Deployment and backups
- Onboarding

## Definition of done

The MVP is not considered complete until a real company can be researched end-to-end, evidence can be inspected, an opportunity can be explained and actioned, an outcome can be recorded, and the workflow survives automated tests and a real-world cohort test.
